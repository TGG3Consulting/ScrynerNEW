# ScrynerNEW: мультибиржевой скринер крипто-фьючерсов

## Описание проекта
Скринер реального времени уровня GodsEye (oculusdei.pro): сбор сделок, стаканов и OI с
бирж, бары 1s/1m, метрики по окнам 1m/5m/15m/1h/24h, алерты по порогам, детекторы
событий (тики, плотности, TWAP, боты), доставка в браузер, Telegram и терминал.
Асинхронная архитектура на Python 3.11+.

## Технологический стек
- Язык: Python 3.11+
- Async: asyncio + aiohttp + websockets
- API: FastAPI (REST + WebSocket)
- Конфигурация: pydantic-settings + YAML
- Логирование: structlog (JSON)
- Хранилище: Redis (горячее состояние), SQLite (dev) / TimescaleDB (prod)
- Тестирование: pytest + pytest-asyncio

## Правила работы

### ОБЯЗАТЕЛЬНО перед началом работы:
1. Прочитай PROJECT_STATE.md
2. Прочитай tasks/BACKLOG.md
3. Прочитай docs/architecture/SCRYNER_ARCHITECTURE.md

### ОБЯЗАТЕЛЬНО после каждого изменения:
1. Обнови PROJECT_STATE.md
2. Добавь запись в CHANGELOG.md
3. Сделай коммит с понятным сообщением

### ЗАПРЕЩЕНО:
- Переписывать файлы целиком (только точечные изменения)
- Менять публичные интерфейсы без согласования
- Оставлять TODO без описания
- Коммитить без проверки тестов
- Использовать хардкод (всё в конфигах)
- Копировать бренд, тексты, иконки и стили оригинала

### Формат коммитов:
```
[MODULE] Краткое описание

- Что изменено
- Почему изменено
```
Примеры: `[COLLECTOR] Add Binance aggTrade stream`, `[METRICS] Fix NATR window`,
`[DOCS] Update PROJECT_STATE after stage 1`.
